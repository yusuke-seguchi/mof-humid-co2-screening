## 2026-09-05 (1): CSD-modified取り込みと母集団v2、Widom再設計

- **CCDC無料登録で取得したCSD-modified（CR 9,835構造）を統合**。狙いは構造(CIF)だけでなく**水安定性MLラベルの適用範囲拡大**。結果、ラベル無しで保守的に落としていたTier C（ランタノイド）が179→964件に復活。判断理由: パイロットでTier C（Tb/Eu/Dy系）が上位に入り、「ラベルが無いだけで落とす」機会損失が大きいと分かったため。
- **Widomサイクル数を20,000→5,000に削減**。1件~2時間は粗選別には過剰（Henry係数の順位はサイクル1/4でも安定）。根拠は完了済み20,000サイクル基準値との比較検証を後で実施することでヘッジ。
- ライセンス: CoRE-MOF modified CIFsはCC BY-NC-SA。ユーザーが大学アカウントで取得しアカデミック利用の整理とした。

## 2026-09-04 (2): パイロット20件 → ML粗選別の放棄（重要な方針転換）

- **観測**: 実験構造20件でML予測とGCMC実測の順位相関がρ=0.16(吸着量)/0.13(選択性)とほぼ無相関。
- **判断**: Stage 1の粗選別をMLからWidom挿入（物理ベースのHenry係数）に置換。**「MLに最終判断させない」設計をさらに進め、粗選別も物理でやる**。MLは診断・補助情報に降格。
- **なぜMLが効かなかったか**: 教師のBW-DBは仮想MOF（Cu/Zn/Vノード、大細孔側）で、我々の母集団（高価数金属・狭細孔・高密度骨格）は分布の端〜外。幾何記述子だけでは金属周りの静電環境を表現できない。文献（Moosavi 2020, RetNeXt 2026）の警告通りの結果であり、保守的設計（Tier A全通し・広Paretoバンド）にしていたことで被害は限定的だった。
- 計算時間の実測: 平均3.0h/件（15,000サイクル）→ 全件は非現実的 → 階層化（Widom全数→GCMC上位）を確定。

## 2026-09-04 (1): RASPA環境構築とパイロット1件目の失敗

- RASPA2 2.0.41をmicromamba/conda-forgeで導入（Apple Siliconネイティブ）。骨格力場は**全元素UFF自動生成**（`src/forcefield.py`）＋吸着質TraPPE＋骨格電荷はCIF同梱のPACMAN DDEC6。換算式はRASPA同梱のFe/Cr/Zn値と一致することで検証。
- **重大バグを踏んだ**: CIFの原子ラベル（Fe1等）が力場の原子種（Fe等）とマッチせず、ガス-骨格VDWが全欠落 → 非物理的吸着量(18 mol/kg)とENERGY DRIFT警告。**修正は `RemoveAtomNumberCodeFromLabel yes`**。教訓として、結果パーサに警告数カウントを組み込み、警告付き結果を自動排除する仕組みにした。

## 2026-09-03 (3): 評価指標の設計

- 文献調査の結論: 「単純指標（吸着量・選択性・APS）はプロセス性能と相関しない」が定説（Danaci 2020, Farmahini 2021）。**指標は『ゲート（足切り）』と『ランキング』に役割分担**し、単一スカラー合成をしない方針に。
- 湿潤特有の罠（CCST 2026）: Henry比や硬いQst閾値は非線形域の勝者を系統的に落とす → 早期ゲートは緩く（recall重視）、湿潤判定は後段で。

## 2026-09-03 (2): ML方針とTrack分離

- ユーザー指摘「物理吸着で学習したモデルは化学吸着を予測できないのでは」→ その通りで、**教師ラベル（古典力場GCMC）自体が物理吸着しか表現できない**構造的限界。対応: (a) ML=内挿の粗選別のみ・最終値=自前GCMC、(b) アミン系等はTrack 2として定量予測から明示的に分離。
- リーク対策: DB間の重複によるテスト水増し（Jablonka 2023）を避けるため、構成ブロック（金属+リンカー）でグループ化したsplitを採用。実際、グループ分割のR²(0.59)は乱数分割の文献値(0.95)より大幅に低く、これが正直な数字。

## 2026-09-02〜03 (1): データベース選定

- 要件: H₂O構造安定・湿度下CO₂吸着・高価数金属多数・Al含有・CO₂吸着量と構造は必須。
- CoRE MOF 2019では高価数母集団が不足（Zr/Hf/Ti/Al/Cr純系368件）→ 調査の結果 **CoRE MOF 2024/2025（水安定性・KH疎水性ラベル同梱）＋MOSAEC-DB（124k、金属酸化状態検証済み）** の2段構えに。
- 高価数金属フィルタを後段の減点でなく**母集団定義の第一原理**に置いたのは、湿潤スクリーニングの真のボトルネックが安定性であるという文献知見（Kwon 2025）と整合。
- 教師データはBW-DB（0.15 bar混合GCMC、吸着熱付き）を主とし、Keskin 2018（実験構造3,816件の選択性）を校正用に確保。
